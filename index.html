🚨 CASE FILE 001 · ภารกิจสืบสวน

โจรหนีเข้าอะพาร์ตเมนต์!

หลังเกิดเหตุโจรกรรม คนร้ายวิ่งหลบหนีเข้าไปในอะพาร์ตเมนต์สูง 4 ชั้น มีทั้งหมด 12 ห้อง ตำรวจส่งเจ้าหน้าที่ A, B, C และ D เข้าไปตรวจค้น แต่ละคนตรวจ 5 ห้องตามเส้นทางของตัวเอง

ภารกิจของคุณ: ใช้เบาะแสทั้ง 9 ข้อหาว่าเจ้าหน้าที่ตรวจห้องไหนบ้าง และค้นหาห้องที่ไม่มีใครตรวจ — ห้องนั้นอาจเป็นที่ซ่อนของโจร!

วิธีเล่นบนมือถือ

① เลือกตัวอักษร A, B, C หรือ D
② แตะห้องเพื่อ เพิ่ม เจ้าหน้าที่ลงไป แตะซ้ำก็ไม่ลบ
③ ถ้าวางผิด กด โหมดลบ แล้วแตะห้องเพื่อเลือกตัวที่ต้องการลบ พร้อมยืนยันอีกครั้ง
④ ใช้เบาะแสตรวจสอบผัง และระบุห้องที่ไม่มีใครตรวจ
🕵️ CASE FILE 001

ตามล่าโจรในอะพาร์ตเมนต์

เลือกเจ้าหน้าที่ แล้วแตะห้องเพื่อเพิ่มลงในแผนผัง แต่ละคนต้องตรวจ 5 ห้อง

🏢 แผนผัง 4 ชั้น

ตะวันตก ← | กลาง | → ตะวันออก

แตะห้องเพื่อเพิ่มเจ้าหน้าที่ที่เลือก

📜 เบาะแสทั้ง 9 ข้อ

  1. เจ้าหน้าที่ทุกคนตรวจคนละ 5 ห้อง และแต่ละห้องต้องอยู่ติดกัน
  2. A เริ่มห้องแรกชั้นบนสุด แล้วลงห้องด้านล่างทันที ก่อนสิ้นสุดที่ชั้น 2 ฝั่งตะวันออก
  3. B ตรวจเพียง 2 ชั้น เริ่มชั้น 3 ฝั่งตะวันตก และจบชั้น 3 ฝั่งตะวันออก
  4. C เริ่มที่ชั้นล่างสุด ไปห้องทางขวามืออีกห้อง แล้วขึ้นไปตรวจทุกห้องในชั้นถัดไป
  5. D เป็นคนเดียวที่ตรวจทั้ง 4 ชั้น และตรวจชั้น 1 มากกว่าชั้นอื่น
  6. มีเพียงห้องเดียวที่เจ้าหน้าที่ตรวจถึง 3 คน
  7. B ไม่ตรวจซ้ำ C เลย แต่ตรวจซ้ำ A ถึง 4 ห้อง
  8. C และ D ตรวจซ้ำกัน 2 ห้อง แต่ห้องสุดท้ายของ D ไม่เคยถูก C ตรวจ
  9. A ตรวจครบทุกห้องของชั้นหนึ่ง ซึ่ง C ไม่เคยตรวจชั้นนั้นเลย

ระบบตรวจตำแหน่งบางส่วนได้ แต่ไม่ตรวจลำดับการเดินทั้งหมด จึงยังไม่ใช่ระบบตัดสินเฉลยที่สมบูรณ์
